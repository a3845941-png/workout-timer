# 筋トレ計測＆インターバルタイマー（Workout Timer）

トレーニング中の**「セット数のカウント」**と**「セット間の休憩時間（インターバル）計測」**をワンクリックで行えるWebアプリです。

## 制作背景・目的
* 筋トレ中に「今何セット目か」「あと何秒休憩するか」を別々のアプリや頭の中で管理する手間をなくすために制作しました。
* プログラミング学習の第一歩として、まずは外部ライブラリやサーバーを使わず、HTML / CSS / JavaScript の基本構造とタイマー処理・DOM操作を自分の手で動かして理解することを目的としています。

## 主な機能
* **トレーニング内容の入力**: 種目名・重量（kg）・目標回数・目標セット数・インターバル秒数を自由に設定可能
* **ワンクリック計測**: 「1セット完了」ボタンを押すと、完了セット数の加算・本日の記録への追加・インターバルタイマーの自動スタートを同時に実行
* **リセット機能**: 記録とタイマーを初期状態に戻す機能

## 使い方（動作確認方法）
1. 本リポジトリの `workout.html` をダウンロード（またはクローン）します。
2. `workout.html` をダブルクリックし、Chrome や Edge などのWebブラウザで開きます。
3. 種目や秒数を入力し、「1セット完了 → 休憩スタート」ボタンを押すと計測が始まります。

## 使用技術
* HTML5
* CSS3
* JavaScript（Vanilla JS）
